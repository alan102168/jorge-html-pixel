# 🎨 Jorge the Truck Driver — HTML Pixel Art

> **Este repositório contém apenas a edição Pixel Art para navegador.** Não tem APK, ROM nem arquivos do Android.

### ▶ Como jogar

- **Arquivo principal:** [`index.html`](index.html).
- Baixe o `index.html` e abra no Chrome, Edge ou outro navegador moderno no PC ou celular.
- O jogo tem visual pixelizado, com resolução interna reduzida e ampliação sem suavização.
- No PC, use o botão **⛶ Tela cheia** para ocupar o monitor sem bordas laterais.
- Controles de teclado (W/S/D/A/P), botões na tela e gamepads reconhecidos pela Gamepad API.

### 📁 Arquivos

- `index.html` — jogo completo, HTML + CSS + JavaScript.
- `tools/verificar_html.py` — verifica estrutura e sintaxe, sem mudar o jogo.
- `.github/workflows/verificar-html.yml` — executa o teste no GitHub Actions.

### 🧪 Testes e publicação

[**Ver verificações automáticas**](https://github.com/alan102168/jorge-html-pixel/actions)

Essas verificações **não substituem** testar jogabilidade em tela cheia, celular, monitor e controle. Para publicar este HTML pela internet, é possível ativar GitHub Pages ou conectar este repositório à Vercel. A publicação não é automática até configurar um desses serviços.
