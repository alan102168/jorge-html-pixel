# Jorge Truck Driver — HTML Pixel Art

Versão independente do jogo para **PC e navegador de celular**, com gráficos pixelados.

## Como jogar

Abra [index.html](index.html) no navegador ou publique este repositório em GitHub Pages/Vercel. Não é necessário instalar aplicativos.

**Versões separadas:** [HTML Normal](https://github.com/alan102168/jogo-sest-senat-2d-caminhao) · [Android Normal](https://github.com/alan102168/jorge-android-normal) · [Android Pixel](https://github.com/alan102168/jorge-truck-driver-android) · [Mega Drive Pixel](https://github.com/alan102168/jorge-megadrive-pixel).
